# Changelog

## 0.9

- Moved the whole theme to the Anthropic palette: Ivory/Slate neutrals, Clay `#D97757` as a sparing accent (color schemes, Plasma controls, icons, mark, splash, wallpapers).
- Fixed color scheme names: in non-English locales Clay Light/Dark were listed as "Breeze".
- Fixed inactive window headers falling back to Breeze blue-grey colors.
- Light lock screen: Complementary colors are now light, so the clock is dark on the light wallpaper.
- Added Clay icons for Desktop, Pictures, Public and other XDG folder names that fell back to Breeze.
- Wallpapers: removed the stray vertical rule and dot.
- Splash uses the wallpaper artwork (seamless hand-off to the desktop) and fades/scales in.
- Apply scripts set Inter as the UI font when installed; uninstall reverts it.
- Regenerated Global Theme previews.
- Redesigned full-color icons as one family: opaque manilla-on-kraft folders with clay glyphs (same look on Light and Dark), warm-grey trash/drives, ivory paper-card tiles for System Settings and Dolphin; separate 16/22 px folder grids.
- File type icons: ivory paper sheets with a colored glyph per category (text, code, script, image, audio, video, archive, PDF, document, spreadsheet, presentation, executable, package, font, disk image); all 517 Breeze mimetype names are mapped, so no Breeze file icons leak through.
- Added a Projects folder icon (`folder-development`, `</>` glyph).
- Icons are generated by `tools/gen_icons.py`; removed the full-color `inode-directory-symbolic` override so symbolic folders stay monochrome.
